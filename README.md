Harbor runs a hosting business from one installation: the public website and storefront, ordering and checkout, billing and payments, automatic provisioning on your servers, domain registration, a client area, support desk, automation and reports. Install it on your own server, connect your control panels and payment gateways, and start selling the same day.

Built on Laravel 12, Vue 3 and Inertia, with a clean light interface, six languages, the Meridian website theme and a module system for servers, gateways, registrars and add-ons.
